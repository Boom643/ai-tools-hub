AI Tools Hub - Frontend Demo
--------------------------------

Structure:
- index.html (dashboard/home)
- login.html, signup.html
- about.html, contact.html
- css/style.css
- js/script.js
- images/ (SVG icons)

Notes:
- Authentication is simulated using localStorage (no backend).
- Signup stores credentials in browser localStorage; login checks against them.
- "Try Now" buttons link to official service pages (open in new tab).
- Contact form uses client-side validation and shows an alert on submit.

To run:
1. Unzip the project and open index.html in your browser.
2. If not signed in, you'll be redirected to login.html. Create an account via signup.html.
